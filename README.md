# 투입ON

PMO와 프로젝트 담당자, 수행사 인원을 연결하는 **인력 투입관리 인터랙티브 프로토타입**입니다. Composio 디자인 가이드의 다크 캔버스·전기 파랑 강조색·단계별 패널 표면을 적용했습니다. [서비스 기획안](docs/PMO-인력투입관리-서비스기획안.md)을 기반으로 구성했습니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상이 필요합니다. 검증한 환경은 Node.js 24입니다.

```sh
npm ci --cache /tmp/tuip-npm-cache
npm run dev
```

개발 서버 포트는 `5173`입니다. 클라우드 환경에서는 제공되는 미리보기 또는 포트 연결 기능으로 확인합니다. 빌드 결과는 `dist/`에 생성됩니다.

```sh
npm run build
npm run preview
```

## 둘러보기

- **주관사:** 전체 현황, 인원 명단, 준비 작업, 교육·서류 검토, 좌석 관리, 문의·알림, 운영 기준.
- **수행사:** 나의 투입 준비, 나의 작업, 교육, 서류, 내 좌석, 문의·변경 요청.
- 상단에서 **주관사 / 수행사**를 전환합니다. 주관사 드롭다운은 **PMO / SFA / 그룹웨어**, 수행사 드롭다운은 **SFA-1~5 / GW-1~5**입니다.
- 시연 기준일은 **2026-11-09**입니다. 교육 수료증 등록과 서류 승인을 구분합니다. 미래 투입일 인원은 준비가 충족되어도 투입 중으로 바로 전환되지 않습니다.
- **운영 기준 → 초기화**로 처음의 10명과 좌석 v1~v4를 복원합니다.

## 추천 시연 흐름

1. SFA 담당자로 SFA-4의 eGIS·두레이 발급 확인을 완료합니다.
2. 수행사 SFA-4로 바꿔 계정 최초 접속 작업이 실행 가능해지는 것을 확인합니다.
3. SFA-3의 교육 화면에서 가상 PDF/이미지 수료증을 등록합니다. 교육 완료와 증빙 검증 상태를 확인합니다.
4. SFA-2의 서류에서 **시연 결과 보기**를 누릅니다. SFA 담당자 검토함에서 보완 요청을 작성하고 수행사 화면으로 돌아가 결과를 확인합니다.
5. 좌석 관리에서 SFA-3을 빈 좌석에 배정합니다. 배정된 좌석의 인원을 다른 빈 좌석으로 드래그하면 사용 기간을 유지한 채 이동하고 새 버전을 기록합니다. 다른 프로젝트 인원·이미 배정된 좌석·과거 버전은 이동할 수 없습니다. 클릭 후 배정 변경 기능도 계속 사용할 수 있습니다. 그룹웨어와 PMO로 바꿔 같은 최신 배치도와 버전 이력을 확인합니다. 같은 브라우저의 별도 탭에도 변경이 반영됩니다.
6. 문의를 등록하고 주관사에서 답변합니다. AI 도우미의 시연용 안내도 확인합니다.
7. 엑셀 템플릿 다운로드 → 작성 → 업로드 → 검증 → 등록 확정과 명단 내보내기를 사용할 수 있습니다.

## 구현 범위와 데이터

React, Vite, Lucide 아이콘, ExcelJS를 사용합니다. 교육·서류 파일은 PDF, PNG, JPG를 선택할 수 있고 최대 10MB입니다. 엑셀은 XLSX, 최대 5MB·500명입니다.

- 명단, 작업 상태, 제출 파일명, 문의, 좌석·버전 기록을 **브라우저 localStorage**에 저장합니다. 같은 출처·브라우저의 탭 간 변경을 동기화합니다.
- 선택한 실제 파일의 미리보기는 **현재 탭의 메모리**에서만 유지됩니다. 새로고침 후에는 제출 메타데이터와 시연용 서식 화면을 보여줍니다. 실제 파일 저장 서버는 없습니다.
- AI 패널과 사전 검토는 **화면·고정 규칙 기반 시연**입니다. 실제 LLM, OCR, 서명 판독은 호출하지 않습니다. AI 검토 완료는 사용자가 `시연 결과 보기`로 진행합니다.
- 두레이는 **미연동**이며 외부 메시지를 전송하지 않습니다. 교육 URL은 PMO가 설정할 수 있고, 미설정 시 안내 화면을 표시합니다.
- 역할·프로젝트 제한은 **프런트엔드 시연**입니다. 실사용 인증·서버 권한 검증·다중 사용자 실시간 서버는 구현하지 않았습니다. 실제 개인정보나 민감 서류를 입력하지 않습니다.
- 좌석은 12석의 단순 원장입니다. 한 좌석에 여러 기간의 예약을 겹쳐 누적하는 전문 예약 엔진은 제외하며, 한 좌석당 한 배정 이력을 현재 상태로 유지합니다. 과거 상태는 버전에서 조회합니다.
- 운영용 승인 시스템·전자서명·외부 계정 발급·LMS·배포는 범위에 포함하지 않습니다.

## 검증

```sh
npm test
npx playwright test
```

업무 규칙 단위 검증과 Chromium 브라우저 시나리오 검증을 제공합니다. 브라우저 검증은 개발 서버가 없으면 자동으로 시작하고, 실행 중이면 재사용합니다. 기본 브라우저 경로는 `/usr/bin/chromium`입니다. 다른 환경에서는 `playwright.config.js`의 경로를 조정하거나 Playwright 브라우저를 설치합니다.

## 디자인 및 좌석 이동

- 디자인 토큰과 화면별 테마: `src/composio-theme.css` (구조·반응형 레이아웃은 `src/styles.css`).
- Inter Variable 폰트를 로컬에서 제공하고 한국어는 시스템 글꼴을 사용합니다. 출처·라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.
- 드래그 이동은 인원 배정을 고정된 좌석 사이에서 옮깁니다. 책상 자체의 위치나 배치도 구조를 편집하는 기능은 아닙니다.
- 드래그할 수 있는 좌석은 잡기 커서와 손잡이가 표시됩니다. 빈 좌석에 놓으면 즉시 이동합니다. 모바일·키보드는 좌석을 선택한 뒤 배정 변경을 사용합니다.
- 이동은 원래 사용 기간을 유지하며, 역할 권한·빈 좌석·기준 버전을 재검사합니다. 다른 탭에서 배치도가 바뀌었으면 재조회 후 다시 이동합니다.
