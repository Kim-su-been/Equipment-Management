# 완료율과 준비 로드맵 개편

## 완료율 정의

모든 카드의 분모는 현재 PMO·프로젝트 조회 범위의 총인원이다. 작업 평균이 아니라 해당 범주를 모두 완료한 **인원 비율**을 표시한다. 등록 대기 인원은 분모에는 포함하되 완료 인원에서는 제외한다. 대상이 없으면 100% 대신 `—`를 표시한다.

| 카드                  | 완료 인원 기준                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| 전체 투입 준비 완료율 | 필수 계정·출입·교육·서류, 기안 기록 6종, 최종 준비 확인을 모두 완료                                   |
| 기안 작성 완료율      | eGIS·패스워드 솔루션·DB Safer·DB 사용자·NGS·소프트매니저 6종 모두 기안 작성 완료 기록                 |
| 교육 완료율           | 배정된 필수 교육 전부 수료·수료증 등록. 증빙 보완·오류가 있으면 미완료이며, 주관사의 증빙 검토는 별도 |
| 필수 제출 서류 완료율 | 투입 단계 필수 서류 전부 제출·승인. 철수 단계 서류 제외                                               |

카드를 누르면 해당 범주의 미완료 인원으로 필터링된 명단을 연다. 전원 완료 시 완료 인원 목록을 연다. 완료 여부 필터로 양쪽을 모두 조회할 수 있다.

## 기안 기록과 호환성

준비 작업의 계정 신청 업무에서 선택 인원의 기안 작성 완료를 일괄 기록한다. 각 인원 행과 작업 상세에서도 기록·취소할 수 있다. 계정 처리와 엑셀 다운로드는 기안 완료 기록을 자동 변경하지 않는다. 저장 시 프로젝트 권한·기록 형식을 확인하며 수행사는 기안 기록을 변경할 수 없다.

인원 고유 ID와 기존 제출·검토 이력을 유지한다. 계정 6종이 전원 필수로 변경되므로 기존 데이터에 빠진 계정 처리·기안 기록이 있으면 완료율은 낮아질 수 있다. 기존 사용자 기록을 임의로 완료 처리하지 않는다. 시연용 초기 명단에는 명시적인 완료 예시가 포함된다.

## 화면

- 주관사 전체 현황은 **투입·수행·철수** 단계의 완료율과 인원수만 요약한다. 단계 카드를 누르면 팝업에서 하위 업무를 펼쳐 대상 인원을 확인하고 기존 작업 상세·기안 기록·초대 링크로 이동한다. 단계 완료율의 분모는 해당 단계 대상 인원이며 상단 카드의 총인원과 구분한다. 철수 단계 대상은 철수 지정 또는 실제 투입 중이고 종료일이 운영 기준의 임박 범위 안인 인원이다.
- 프로젝트별 준비 현황도 상단 전체 투입 준비 완료율과 같은 기준으로 퍼센트와 완료 인원/총인원을 표시한다. 클릭하면 해당 프로젝트의 미완료 명단으로 이동한다. 전원 완료 시 완료 명단으로 이동한다.
- 수행사 홈은 가로 로드맵만 표시하고 단계 클릭 시 상세 작업을 팝업으로 연다. 팝업에서 작업 상세로 이어지며 Escape·닫기 후 원래 버튼으로 포커스를 돌려준다.
- 로드맵 바로 아래에 **지금 내가 할 일 / 주관사에서 준비 중인 항목**을 2열로 표시한다. 좁은 화면에서는 1열로 배치한다.
- 교육·서류는 **나의 작업** 하위 메뉴와 내부 탭으로 접근한다. 우리금융그룹 스타일의 파란 헤더·사이드바와 캐릭터를 유지한다.

## 확인 방법

`npm test`에서 완료율 분모·필수 계정·별도 기안 기록·반복 기록·권한·단계 분류를 확인한다. `npm run test:work-ux`는 카드 필터, 로드맵 팝업과 키보드 복귀, 2열 배치, 하위 메뉴, 기존 메일 승인·서류 보완 흐름을 확인한다. `npm run test:batch`는 선택 명단 엑셀과 수동 기안 기록·취소·새로고침 유지 여부를 확인한다. HTML 시연은 브라우저 저장소를, 서버형은 기존 서버 저장 경로를 사용한다. 사내 기안 결재·계정 발급 연동은 포함하지 않는다.
