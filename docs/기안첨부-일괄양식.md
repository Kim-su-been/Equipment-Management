# 준비 작업별 기안 첨부 엑셀

## 사용자 흐름

PMO·프로젝트 담당자의 **준비 작업** 기본 보기를 `단계·업무별 묶음`으로 변경했다. **투입 → 수행 → 철수** 단계 아래 세부 업무를 펼치면 대상 인원과 상태가 나온다. 신청할 인원 선택 → **선택 인원 기안 첨부 엑셀** → 미리보기·공통 정보 입력 → **양식 다운로드** 순서로 사용한다.

| 단계 | 세부 업무                                                               | 내보내기                                                                           |
| ---- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 투입 | 보안교육 실시 → 보안준수 서약서                                         | 기존 교육·보안서약서 작업으로 연결, 신규 서약서 작성은 교육 완료 후 가능           |
| 투입 | eGIS, 패스워드 솔루션, DB Safer, DB 사용자, NGS, 소프트매니저 계정 신청 | 계정별 예시 신청 명단. DB명·스키마·권한·접속 IP 등 해당 양식의 추가 항목 입력 지원 |
| 수행 | 업무공간 출입 등록                                                      | 기존 출입 작업과 예시 신청 양식 재사용                                             |
| 철수 | 비밀준수 서약서, 파기확인서, 철수확인서 징구                            | 서류별 예시 징구 현황 대장. 법적 서약서 원본 생성 기능과 구분                      |

기존 두레이·개인정보 관련 작업과 프로젝트별 추가 작업은 **기존·추가 준비 업무**에 유지했다. 기한순 작업·인원별 요약 보기 및 완료 작업 조회도 사용할 수 있다.

## 처리 기준

- 프로젝트 담당자는 담당 프로젝트, PMO는 현재 조회 범위의 인원만 선택한다. 선택 인원의 고유 ID로 기존 등록 정보를 조회하며 이름이 같다는 이유로 합치지 않는다.
- 일괄 신청은 본인 등록 완료·선행 작업 충족·미완료 인원을 대상으로 한다. 보류·취소·완료 인원은 제외하며, 철수 단계는 투입 중·철수 예정·철수 인원을 대상으로 한다.
- 선택 후 작업 상태가 바뀌면 해당 인원을 선택에서 제외한다. 엑셀 생성 직전에도 선택 범위와 작업 상태를 검사한다. 제외된 자리를 다른 인원으로 자동 채우지 않는다.
- 기존 필수 준비율을 임의로 바꾸지 않도록 추가 계정·철수 작업은 기본 필수 항목에 넣지 않았다. 실제 필요한 계정 신청은 담당자가 인원을 선택해 처리한다. 기존 완료 작업·제출 원본·검토 이력은 유지한다.
- 공식 양식이 없다는 사용자 답변에 따라 **예시 양식**으로 구현했다. 고유 정보는 등록 값에서 읽고, 추가 정보는 입력한 값만 넣는다. 없는 값은 **미입력**으로 표시하고 엑셀에서도 색으로 구분한다.
- 다운로드는 기안 상신·계정 생성·징구 완료를 의미하지 않는다. 사내 결재·발급·징구 결과를 확인한 뒤 기존 작업 완료 기능으로 기록한다.

## 구현·검증

기존 작업 상태·프로젝트 권한·ExcelJS 내보내기를 재사용한다. 서버·DB 구조는 변경하지 않았으며, HTML 시연과 서버형 서비스 모두 같은 작업·양식 함수를 사용한다.

- 로직·서버 테스트 **60개**, 서버형 브라우저 시나리오 **8개** 통과.
- 신규 일괄 검증: 선택한 인원만 포함한 eGIS 엑셀, DB명·권한 입력, 다른 창에서 완료된 인원의 선택 해제, 철수 현황 시트, 프로젝트 제한, 모바일 표시, 다운로드 후 작업 상태 유지 확인.
- 기존 HTML 검증: 인력계획서 A/B, 초대·본인 등록, 보안교육 후 서약서 제출·승인, 증빙 원본·ZIP·엑셀, 백업·복원, 메일 승인·보완·재제출 경로 통과.

```bash
npm test
npm run test:browser
npm run build:offline
npm run test:batch
npm run test:work-ux
npm run test:html
```

실제 사내 기안 상신·계정 발급 시스템은 미연동이며, 공식 첨부 양식을 확보하면 업무별 열 매핑을 교체해야 한다.
