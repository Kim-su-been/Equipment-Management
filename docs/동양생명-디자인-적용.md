# 동양생명 디자인 적용

## 적용 범위

사용자가 제공한 동양생명 CI·캐릭터 소개 화면 캡처를 기준으로 파트너360의 표현 계층을 변경했습니다. 인력계획서 등록, 개인별 초대, 준비 작업, 메일 검토·승인, 퍼포먼스 관리의 업무 로직·데이터·화면 배치는 유지합니다.

| 항목      | 적용 내용                                                                              |
| --------- | -------------------------------------------------------------------------------------- |
| 화면      | 짙은 회색 메뉴(`#4b535a`)·Guardian Blue 헤더(`#5f97c8`), 흰 카드와 연한 회색 작업 배경 |
| 주 색상   | 캡처의 Guardian Blue를 참고한 `#5f97c8`                                                |
| 주요 조작 | 글자 대비를 확보한 진한 파랑 `#2b679b`                                                 |
| 상태      | 완료·주의·오류의 기존 의미별 색상과 텍스트 유지                                        |
| 캐릭터    | 젤로디와 친구들 그룹 이미지, 젤로디 안내 이미지                                        |
| 작은 CI   | 상단바 중앙의 밝은 영역에 캡처를 참고한 `수호천사동양생명` 텍스트 로고타입 표시        |
| 그래프    | 기존 비교 방식·값·축을 유지하면서 막대와 범례 색상을 조정                              |

색상은 캡처를 보고 정한 화면용 근사값이며, 공식 Pantone 색상의 RGB 변환값을 검증한 것은 아닙니다. 캐릭터는 제공된 캡처를 참고해 이미지 생성·편집 도구로 제작한 시연용 이미지로, 공식 원본 파일을 내려받은 자산은 아닙니다. 작은 CI 역시 캡처를 참고해 구성한 SVG 텍스트 로고타입이며 공식 배포 원본은 아닙니다. 공식 홈페이지를 직접 열어 원본을 확인한 것으로 표현하지 않습니다.

참고 페이지: [CI 소개](https://www.myangel.co.kr/Company/Introduce/CoBrnd), [캐릭터 소개](https://www.myangel.co.kr/Company/Introduce/CoCha). 실제 작업의 시각 자료는 사용자가 채팅에 제공한 캡처입니다.

## 구현과 확인

공통 스타일 마지막에 전용 테마를 추가하고 캐릭터 이미지 경로를 교체했습니다. 서버형·HTML 단독 시연이 같은 테마를 사용하며 HTML에는 이미지를 포함합니다.

| 실행한 확인             | 결과                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------- |
| HTML 단독 시연 빌드     | 성공                                                                                                     |
| 업무 화면 브라우저 검증 | 인원 표시, 필터, 선행 작업, 최종 확인·투입 상태, 메일 승인, 서류 보완·재제출, 모바일 배치·대비 확인 통과 |
| 퍼포먼스 브라우저 검증  | 프로젝트·팀 토글, 인원별 그래프, 지표 근거, 개인 상세, 시연 자료 재수집, 범위별 조회, 내보내기 확인 통과 |
| 서버형 브라우저 검증    | 등록·메일 관련 8개 시나리오 통과                                                                         |
| HTML 브라우저 검증      | 등록·초대·교육·서류·메일·파일 다운로드와 백업·복원 흐름 통과                                             |

이번 작업으로 실제 ITGS·메일·AI 모델·본인인증·Dooray 외부 연동이 추가된 것은 아닙니다. 기존 HTML의 가상 데이터·규칙 기반 시연 범위를 유지합니다.

## 확인 방법

미리보기 ZIP을 내려받아 압축을 풀고 `readyboard-offline.html`을 Chrome 또는 Edge에서 엽니다. 기존 브라우저 저장 데이터는 유지됩니다. 소스에서 생성하려면 `npm ci` 후 `npm run build:offline`을 실행합니다.

상단 CI는 넓은 화면에서 제목·도구 사이의 정중앙에 배치하고, 좁은 화면에서는 중앙 로고와 제목·도구를 두 줄로 나누어 겹침을 방지합니다. 왼쪽 메뉴에는 CI를 중복 표시하지 않습니다.
