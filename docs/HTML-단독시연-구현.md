# 레디보드 HTML 단독 시연

## 실행

`preview/readyboard-offline.html`을 Chrome 또는 Edge에서 연다. ZIP에도 같은 `readyboard-offline.html`이 포함된다. Node.js 설치, `npm run dev`, 서버 접속, API 키가 필요하지 않다. 푸른색 메뉴·헤더, 흰 작업 영역, 우리금융그룹 참고 캐릭터와 기존 업무 화면을 유지했다.

상단에서 PMO·SFA 담당자·그룹웨어 담당자·수행사를 선택한다. 수행사 화면에서는 등록을 마친 인원을 선택할 수 있다. 수행사를 등록하려면 PMO에서 개인 초대를 발급하고 **초대 링크 열기**에 붙여 넣거나 같은 파일의 링크로 이동한다. 링크가 가리키는 한 명의 기존 기록에 추가 정보를 저장한 뒤 수행사 화면으로 이어진다. 기존 링크 재발급·만료·사용 완료 검사를 브라우저에서 수행한다.

## 저장과 이동

모든 상태와 업로드 원본은 **현재 브라우저의 IndexedDB**에 보관한다. 새로고침·화면 전환으로 초기화되지 않는다. 시연 초기화는 별도 확인 후 실행한다. 브라우저에서 저장소를 차단한 경우 현재 탭 메모리로 동작하고 상단에 저장 제한을 표시한다. 이때는 닫기 전에 백업한다.

**시연 백업**은 명단뿐 아니라 실제 제출 파일, 엑셀 원본/행 연결, 초대 유효기간과 사용 상태, 메일·검토·반영 이력까지 JSON으로 내려받는다. **백업 불러오기**는 이를 다시 가져온다. 파일명·위치를 바꾸거나 다른 PC·브라우저로 옮기기 전 백업하고 새 위치에서 복원한다. 백업은 합성 데이터 시연용으로 관리한다.

HTML만 전달하면 초기 합성 명단이 보이고 다른 PC의 변경 사항과 자동 공유되지 않는다. 같은 PC·브라우저에서는 같은 HTML 파일에서 링크를 열어 시연한다. 운영용 서버 권한 검증과 달리 상단 역할 선택은 발표용 전환 기능이다.

## 구현

`scripts/review/adapter.js`가 기존 API 계약을 브라우저 안에서 처리한다. API 요청은 네트워크로 나가지 않는다. 파일은 Blob으로 IndexedDB에 저장하며 내려받을 때 같은 바이트를 반환한다. 변경 요청은 직렬 처리하고 저장 실패 시 상태를 되돌린다. 브라우저의 백업·저장 오류는 화면에 표시한다.

기존 검증·처리 함수를 양쪽 실행 환경에서 공유한다.

- `src/workbook.js`: 기존 ExcelJS 파서·매핑·행 추출. Node Buffer 의존 부분을 표준 Uint8Array/DataView로 변경했다. 서버의 `server/workbook.js`는 같은 함수를 재노출한다.
- `src/actor-scope.js`, `src/state-permissions.js`: 기존 역할 범위·변경 전 값 확인·작업 선행 조건·증빙 연결 검증. 서버에서도 재사용한다.
- `src/personnel-records.js`, `src/personnel-workflow.js`, `src/mail-application.js`, `src/mail-request-validation.js`: 같은 UUID 인원 생성·개인별 작업/일정 변경·메일 초안 검증.
- 기존 `PlanImport`, `SelfRegistration`, `OnlineDocument`, `EvidenceManager`, `MailReviewPage` 등 실제 UI를 그대로 렌더링한다. 파일 모드의 초대는 `/invite/...` 서버 경로 대신 같은 HTML의 `#invite=...` 경로를 사용한다.

단일 HTML에 JS·CSS·폰트·캐릭터·서류 원본·예제 XLSX를 포함한다. `export:html`과 기존 미리보기 다운로드 경로는 전체 브라우저 시연을 생성한다. 서버 연결용 자산 내보내기는 `export:server-html`로 따로 제공한다.

## 다시 생성 및 검증

```bash
npm ci
npm run export:html
npm run test:html
npm test
npm run test:browser
npm run build
```

`tests/review-html.mjs`는 기존 5통/2초안·개별 승인·재확인을 검사한다. `tests/offline-html.mjs`는 네트워크를 끄고 API 서버 없이 생성된 HTML만 브라우저에 로드하여 XLSX·초대·본인 등록·문서·수료증·승인·원본 ZIP/양식 다운로드·작업 추가·권한 범위·새로고침·백업/초기화/복원을 검사한다. 업로드한 파일과 복원한 원본 바이트도 비교하며 실제 네트워크 API 호출이 없는지 확인한다.

검증 결과: 기존 서버·로직 테스트 41개, 서버형 브라우저 시나리오 8개, 단독 HTML 검증 2개 스크립트 모두 통과했다. 독립 HTML은 네트워크를 끈 상태에서 추가 API 요청 없이 동작했다. A/B 양식, 동명이인·생년 확인, 링크 만료·재발급·중복 제출, 원본 ZIP CRC, 백업 복원 후 원본 바이트 일치도 확인했다. 프로덕션 빌드도 성공했다.
